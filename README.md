# RotorCraft Evolution: releases

Flyable helicopters for DayZ 1.30: Mosquito, MH-6 and AH-6 Little Birds, Gazelle and the 20 mm cannon Gazelle, Black Hawk and the door-gun Black Hawk, and the CH-47 Chinook (Experimental).

**The easiest way to install is the Steam Workshop:** [RotorCraft Evolution](https://steamcommunity.com/sharedfiles/filedetails/?id=3833947743), plus [Community Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=1559212036).

This repository holds the same builds as zip downloads, with the server files and guides, for anyone who can't use the Workshop. Every release lists its changes and install steps. Get the newest one from **[Releases](https://github.com/sdfska/RotorCraft-Evolution-Releases/releases/latest)**.

- Website: [rotorcraftevolution.com](https://rotorcraftevolution.com): videos, the public server, setup guide and FAQ
- Support and bug reports: [Discord](https://discord.gg/jeBrvKrfwB)

**No repacks, no re-uploads, no merging this mod into server packs or modpacks.** Load it from the Workshop item or from these official releases.
